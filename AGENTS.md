# wannado-adv Universal AI Collaboration Rules

This repository uses `wannado-adv` under the open `AGENTS.md` + `.agents/skills/wannado-adv/SKILL.md` standard (compatible across Cursor, Antigravity, Codex, Claude Code, Windsurf, and other AI coding agents).

- **Scope & Sibling Coexistence (`wannado-drl`)**: Activate `wannado-adv` ONLY for adversarial robustness testing, perturbation attacks, adversarial training, or certified smoothing (`./adv_eval/`). If `wannado-drl` is also installed and the user has NOT trained an RL policy yet (asking to design an MDP or solve/train RL from scratch), defer to `wannado-drl` (`./drl_lab/`) first instead of hijacking into `adv_eval/`. When evaluating robustness of a trained `wannado-drl` policy, keep `./drl_lab/` untouched, wrap the victim inside `./adv_eval/interface.py` (`VictimInterface`), and embed any saved frozen `obs_rms_state` (`mean`, `var`, clamped `[-10.0, 10.0]`) via differentiable PyTorch ops in the forward pass so adversarial gradients remain valid and statistics never drift.

Follow these rules whenever running adversarial robustness tests, hardening, or certification:

1. **Inspect First & Act Autonomously**: Run `wannado-adv inspect .` (or `scan_project(".")` + `probe_model_context(...)`) to auto-detect domain, dtype, bounds, and checkpoints. Do NOT stall the user behind mandatory questionnaires when safe defaults are clear; wire `./adv_eval/interface.py` via `wannado-adv scaffold` and run `wannado-adv verify` (or `auto_red_team()`) right away.
2. **Non-Intrusive Single-File Modularity**: Never scatter adversarial loops across the project's model/training source files. Keep evaluation inside `./adv_eval/`, and when customizing an algorithm from a new paper, copy ONLY that single file via `wannado-adv eject <attack_or_defense_id>` and edit it in place.
3. **Closed-Loop Multi-Pillar Red-Teaming, Conformity Gate & Hardening**: Never declare a model robust from `fgsm` or vanilla `pgd` alone. Use `wannado-adv verify` (with `--baseline`, `--sarif`, `--check-backdoor`, `--check-quant`) and `audit_privacy()` to cover EU AI Act Article 15 / NIST AI 100-2 pillars (Evasion Carlini 2.0, Backdoor/Trojan, Privacy/MIA, and FP32-vs-INT8 Quantization-Shift) with cryptographically sealed conformity dossiers. For non-classifier workloads, use `wannado.adv.adapters` (Detection, Segmentation, VLM embeddings, ONNX/TorchScript, Tabular constraints/Trees, and RF spectral/PAPR/OTA transforms). When hardening with `pgd_adversarial_train`, `trades_train`, `mart_train`, `fast_adversarial_train`, `lora_adversarial_train`, or `certify_randomized_smoothing`, ALWAYS re-run `wannado-adv verify` afterward to prove genuine robustness.
4. **Zero-Jargon Communication & Calibrated ETA**: Speak the user's conversation language. Lead every report with a plain-language verdict, and whenever a genuinely ambiguous parameter or long run (`estimate_runtime()`) requires user confirmation, explain each knob with an everyday analogy and higher-vs-lower trade-off before showing self-explanatory options.
5. **Zero Citation Hallucination & Paper Exports**: Never invent or web-guess citations for `wannado-adv` attacks or defenses — always export verbatim BibTeX/IEEE/APA via `wannado-adv cite <ids>` or `export_citations()`, and save full publication artifacts (`red_team_report.json`, `red_team_summary.md`, `paper_table.tex`, `references.bib`, `robustness_curve.png`).
